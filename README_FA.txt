# ربات تلگرام جست‌وجوی فایل‌های خودت

این پروژه برای جست‌وجو در فایل‌هایی است که خودت مالکشان هستی یا مجوز استفاده از آن‌ها را داری.
فایل‌های CSV، TXT و XLSX پشتیبانی می‌شوند. فایل پس از دریافت یک‌بار وارد SQLite FTS5 می‌شود تا جست‌وجوهای بعدی سریع‌تر باشند.

## نکته مهم
- این پروژه برای داده‌های مجاز و غیرحساس است؛ برای جست‌وجوی انبوه اطلاعات خصوصی اشخاص، اطلاعات بانکی، رمزها یا داده‌های افشاشده استفاده نکن.
- چند نام ستون حساس شناخته‌شده از فهرست‌سازی کنار گذاشته می‌شوند؛ این فیلتر کامل و تضمین امنیتی نیست. قبل از بارگذاری، خودت فایل را از داده‌های حساس پاک‌سازی کن.
- سرعت ۲۰ ثانیه تضمین‌شدنی نیست و به حجم فایل، سرور و نوع جست‌وجو بستگی دارد.
- فایل‌ها و پایگاه داده روی سروری که ربات را اجرا می‌کند ذخیره می‌شوند. سرور باید فضای کافی و پشتیبان‌گیری امن داشته باشد.

## راه‌اندازی روی سرور لینوکس
نیازمندی‌ها: Python 3.10+ و SQLite با پشتیبانی FTS5.

1. پوشه پروژه را روی سرور قرار بده.
2. محیط مجازی بساز:
   `python3 -m venv .venv`
3. فعالش کن:
   `source .venv/bin/activate`
4. نصب:
   `pip install -r requirements.txt`
5. فایل `.env.example` را به `.env` کپی کن و مقدارها را وارد کن.
6. متغیرهای محیطی را در پنل میزبان تنظیم کن یا از ابزار امن بارگذاری env استفاده کن.
7. اجرا:
   `python bot.py`

## گرفتن توکن ربات
در تلگرام به `@BotFather` برو، دستور `/newbot` را بزن و مراحل را انجام بده. توکن را فقط در متغیر `BOT_TOKEN` روی سرور قرار بده؛ آن را در چت یا برای هیچ‌کس نفرست.

## پیدا کردن شناسه عددی تلگرام مدیر
از یک ربات معتبر نمایش شناسه عددی یا ابزار مورد اعتماد خودت استفاده کن. شناسه عددی را در `ADMIN_IDS` قرار بده. اگر چند مدیر داری، با کاما جدا کن.
پس از راه‌اندازی، فقط شناسه‌های داخل `ADMIN_IDS` اجازه کار دارند.

## فرمت‌ها
- CSV: ردیف اول باید عنوان ستون‌ها باشد.
- TXT: هر خط یک رکورد محسوب می‌شود.
- XLSX: ردیف اول هر برگه عنوان ستون‌هاست.
- فعلاً XLS قدیمی، XLSM، فایل‌های رمزدار و فایل‌های چندگیگابایتی مستقیم پشتیبانی نمی‌شوند. برای دیتاست‌های خیلی بزرگ باید ابتدا ساختار، فضای دیسک و روش ورود داده متناسب‌سازی شود.

## فرمان‌ها
- `/start` شروع
- `/help` راهنما
- `/stats` آمار ردیف‌ها و منابع

## محدودیت نسخه اول
این نسخه جست‌وجوی همه واژه‌ها را با هم انجام می‌دهد (AND). جست‌وجوی فازی، غلط‌یابی، فیلتر انتخاب ستون و خروجی اکسل هنوز اضافه نشده‌اند.
