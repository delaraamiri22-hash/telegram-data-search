نسخه آزمایشی مخصوص Render Web Service

در GitHub فایل‌های این بسته را در ریشه مخزن آپلود و فایل‌های قبلی را جایگزین کن.
در Render یک Web Service از مخزن بساز.
Build Command: pip install -r requirements.txt
Start Command: python bot.py

در Environment:
BOT_TOKEN = توکن جدید BotFather (در GitHub یا چت منتشر نکن)
ADMIN_IDS = شناسه عددی تلگرام مدیر

هشدار: توکن قبلی که در چت افشا شده باید در BotFather باطل شود.
این نسخه صرفاً آزمایشی است. فضای دیسک رایگان Render ماندگار نیست و با ری‌استارت ممکن است فایل‌ها و SQLite پاک شوند. سرویس رایگان ممکن است بخوابد؛ زمان پاسخ زیر ۲۰ ثانیه تضمین نمی‌شود.
فقط داده‌های مجاز و غیرحساس را وارد کن. فیلتر نام ستون حساس کامل نیست؛ قبل از آپلود داده‌ها را پاک‌سازی کن.
